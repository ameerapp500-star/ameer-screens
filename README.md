# أمير للشاشات — Ameer Screens

مشروع Android تأسيسي مستقل.

الموجود:
- اسم وهوية التطبيق الأساسية.
- شاشة عربية أولية لإدخال كود التفعيل.
- GitHub Actions لبناء APK تجريبي تلقائياً.

غير المنجز:
- خادم التفعيل وقاعدة بيانات الأكواد.
- لوحة إدارة التراخيص.
- مشغل الوسائط ووظائف Android Auto.
- توقيع إصدار إنتاجي.

زر التفعيل لا يمنح ترخيصاً؛ خادم التراخيص لم يُربط بعد. لا توزّع هذه النسخة على المستخدمين.
